
# Smart Home Activity Recognition Using LSTM

## Project Overview
This project uses Long Short-Term Memory (LSTM), a type of recurrent neural network, to recognize smart home activities from sensor data.

## Technologies Used
- Python
- TensorFlow/Keras (if used in the implementation)
- Pandas and NumPy
- LSTM
- Synthetic sensor dataset

## Input Features
- Door status
- Temperature
- Person presence
- Light status

## Methodology
1. Generate and prepare synthetic sensor data.
2. Preprocess the data for model training.
3. Train an LSTM model to recognize activity patterns.
4. Predict activities based on sensor inputs.
5. Display the model's predictions.

## Dataset
The project uses a synthetic dataset for experimentation and model development.

## Note
This is a prototype project. The data is simulated and does not represent real-world sensor deployment.
